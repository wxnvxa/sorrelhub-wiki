# Logo Assets

This folder stores public Sorrel Hub logo history used by the README timeline.

## Files

- `01-original-2024.png` - first known Sorrel Hub logo.
- `02-photoshop-spring-2025.webp` - spring 2025 Photoshop-era logo asset.
- `03-english-revival-2025.png` - English-audience revival logo.
- `nextgen-v1-early.png` - earliest NextGen era logo with gradient background.
- `nextgen-icon-early.png` - early NextGen star icon design.
- `nextgen-clean.png` - clean NextGen flat logo.
- `current-v1.png` - first version of the current flat logo.
- `current-v2.png` - second version of the current flat logo with background pattern.
- `current-icon.png` - current minimalist star icon.
- `current-logo-3d.png` - static 3D version of the current star logo.
- `current-logo-3d-animated.gif` - animated 3D star logo (sparkle.gif).
- `v2-unreleased-animation.png` - visual artifact from unreleased Sorrel Hub v2.
