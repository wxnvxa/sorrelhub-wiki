# Start Here

Sorrel Hub is a developer ecosystem created by Winner / Lox. It started as a Roblox script hub idea and later grew into a wider set of projects: website, backend/API, WinWare, LoveyWare, TargetWare, Sorrel AI, and separate tools.

## Short Version

- `Sorrel Hub` - the main brand.
- `Sorrel Hub: NextGen` - the current reboot era.
- `WinWare` - Winner's Roblox/Luau project line.
- `LoveyWare` - lovey0x's script project.
- `TargetWare` - a project that grew from predict tp and target esp.
- `Sorrel AI` - an AI bot in the Sorrel Hub ecosystem.
- `ExploitRPC` - an open-source Windows tool for Discord Rich Presence.

## Why The History Has Several Reboots

Sorrel Hub did not start as a finished commercial product. It grew through Discord servers, Roblox scripts, visual redesigns, restarts, and new names.

Main eras:

1. The first idea and old Sorrel Hub.
2. Official deletion of old Sorrel Hub.
3. Unreleased Sorrel Hub v2.
4. English-audience revival attempt.
5. `NSW x SH`.
6. `Sorrel Hub: NextGen`.
7. Current shift toward a clearer web/dev ecosystem.

## What NextGen Means

`NextGen` is the name of the current era. It does not have to stay in the brand forever.

Read it like this:

```txt
Sorrel Hub - main brand
NextGen - current chapter/reboot
```

In the future, the public name may return to just `Sorrel Hub`.
