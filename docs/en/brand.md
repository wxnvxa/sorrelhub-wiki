# Brand

## Name

Main brand:

```txt
Sorrel Hub
```

Current era:

```txt
Sorrel Hub: NextGen
```

`NextGen` does not have to stay in the name forever. It is closer to a marker for the current post-reboot era.

## Origin

The name came from two parts:

- `sorrel` - the plant
- `hub` - a word from Roblox script hub culture

Working explanation:

```txt
Sorrel Hub started as a Roblox script hub idea and grew into a broader dev ecosystem.
```

## Style

Current web/API style:

- black and white palette;
- `JetBrains Mono Medium`;
- clean minimalism;
- less unnecessary decoration;
- backend/API screens should look like technical endpoints, not landing pages.

## Positioning

Short version:

```txt
Sorrel Hub is a small dev ecosystem by Winner and lovey0x.
```

Wider version:

```txt
Sorrel Hub is a developer ecosystem for web tools, Roblox scripting projects, UI experiments, and AI-assisted utilities.
```
