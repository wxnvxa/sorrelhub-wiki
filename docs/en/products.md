# Products

## Sorrel Hub

The main brand and umbrella for the ecosystem.

Directions:

- web dashboard
- backend/API
- Luau / Roblox scripts
- UI/UX
- AI tools
- desktop/tools experiments

## Sorrel Hub: NextGen

The current era after the November 2025 reboot.

`NextGen` should be understood as a chapter/reboot name. In the future, the public name may return to just `Sorrel Hub`.

## Web Dashboard

The Sorrel Hub web layer covers the website, account system, connected services, and future dashboard.

The current web direction is moving toward React / Next.js.

Planned domain structure:

- `sorrelhub.xyz` - main website
- `api.sorrelhub.xyz` - API and loader
- `aibot.sorrelhub.xyz` - Sorrel AI
- `cabinet.sorrelhub.xyz` - possible future cabinet

The cabinet is not currently split into a separate subdomain.

## WinWare

WinWare is Winner's Roblox/Luau project line.

Known stages:

- `WinWare:PVE` - first version, created on 2025-11-23.
- `WinWare Pre-Alpha Test` - announced on 2025-12-31 and reopened on 2026-01-01.

`WinWare:PVE` was a farming script for `Build A Boat For Treasure`, used `Luna UI`, had a key system, and is now discontinued.

## LoveyWare

LoveyWare is lovey0x's script project.

Facts:

- published on 2025-11-24
- first target: `Violence District`
- on 2025-12-08, it received a new key system and more modules
- on 2026-01-01, it was announced that LoveyWare would no longer work with `Violence District`
- new focus: less popular or easier games

## TargetWare

TargetWare grew from `predict tp` and `target esp`.

Facts:

- officially created and published on 2026-04-18
- related to Roblox gameplay modifications and script analysis
- early predict tp tests are part of the story of how Winner and lovey0x met

## Sorrel AI

Sorrel AI is an AI bot in the Sorrel Hub ecosystem.

Domain:

```txt
aibot.sorrelhub.xyz
```

The first launch was on 2025-12-14. Historically, it was an AI bot without restrictions or warnings that wrote any code. It did not run for long and was sometimes started manually.

## ExploitRPC

ExploitRPC is an open-source Windows app created on 2026-02-10.

Purpose:

- track activity in supported Roblox injectors;
- show Discord Rich Presence;
- switch status between idle and Roblox activity.
