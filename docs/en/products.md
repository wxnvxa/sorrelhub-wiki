# Products

## Sorrel Hub

The main brand and umbrella for the ecosystem.

Historically, Sorrel Hub started as a Discord server for Winner's Roblox game `Щавель обби` and future places. This detail matters because old Sorrel Hub was not a script hub in the current meaning. It was more about a game community and future Roblox projects.

Later, around September-October 2025, Sorrel Hub started turning into a project around Roblox scripts, web, backend/API, and other dev directions.

Directions:

- web
- backend/API
- Luau / Roblox scripts
- UI/UX
- AI tools
- desktop/tools experiments

## WinWare

WinWare is a Roblox/Luau direction focused on HvH, Visuals, and related modules.

In simple terms, WinWare should not be described only as a farming script. It had a PVE history, but the current meaning is wider: visuals, HvH logic, gameplay modules, UI, and Roblox/Luau experiments.

Known stages:

- `WinWare:PVE` - first version, created on 2025-11-23.
- `WinWare Pre-Alpha Test` - announced on 2025-12-31 and reopened on 2026-01-01.

`WinWare:PVE` was a farming script for `Build A Boat For Treasure`, used `Luna UI`, had a key system, and is now discontinued.

## LoveyWare

LoveyWare is Lovey0x's direction, not just "one script".

If WinWare is described through HvH/Visuals, LoveyWare is better described as a bypass-oriented direction and a set of modules around that approach. This is part of the current Sorrel Hub story because Lovey0x is a co-owner of Sorrel Hub, not just the author of a separate file.

Facts:

- published on 2025-11-24
- first target: `Violence District`
- on 2025-12-08, it received a new key system and more modules
- on 2026-01-01, it was announced that LoveyWare would no longer work with `Violence District`
