# Glossary

## Sorrel Hub / SH

Main brand and project ecosystem. Original Sorrel Hub was a Discord server for the Roblox game `Щавель обби` and future places, not a script hub.

## Sorrel Hub: NextGen

Previous Sorrel Hub reboot era after `NSW x SH`. It is historical context after `2026-06-16 16:00 UTC+5`.

## Winner / Alfredo Swagger

Winner / Alfredo Swagger - creator of original Sorrel Hub and one of the owners of the current Sorrel Hub.

## Lovey0x

Co-owner of the current Sorrel Hub and owner of the LoveyWare direction.

## Lox / lox_228

Co-owner of old Sorrel Hub during the pre-NextGen era until the end of that era. Not the creator of the current Sorrel Hub.

## WinWare / WW

Roblox/Luau direction focused on HvH, Visuals, and related modules.

## WinWare:PVE

First WinWare version, created on 2025-11-23.

## LoveyWare / LW

Lovey0x's direction focused on bypass-oriented modules and similar tooling.

## TargetWare

A project that grew from `predict tp` and `target esp`.

## Sorrel AI

Historical Sorrel Hub AI bot. It is not documented as an active current web app.

## NSW

`NeverStopWinning`.

## NSW x SH

Early project name before the rename to `Sorrel Hub: NextGen`, now historical context.

## Loader

Backend mechanism that serves script code to the client.

## Sub ID

Subscription or access identifier used by loader logic.

## SHProtect

Custom loader/source-code protection.

## Cabinet

Sorrel Hub user cabinet. It belongs to the main website/dashboard direction for now, with no active plan to move it to a separate subdomain.

## Vercel

Platform for frontend / Next.js projects.

## Railway

Platform for backend/API hosting.

## Turnstile

Cloudflare Turnstile, anti-bot protection for login/register flows.
