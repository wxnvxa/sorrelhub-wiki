# Начать здесь

Sorrel Hub - dev-экосистема, созданная Winner / Lox. Проект начался как идея Roblox script hub, но со временем вырос в более широкий набор проектов: сайт, backend/API, WinWare, LoveyWare, TargetWare, Sorrel AI и отдельные tools.

## Самое короткое объяснение

- `Sorrel Hub` - главный бренд.
- `Sorrel Hub: NextGen` - текущая эпоха и перезапуск проекта.
- `WinWare` - Roblox/Luau направление Winner.
- `LoveyWare` - скрипт lovey0x.
- `TargetWare` - проект, выросший из predict tp и target esp.
- `Sorrel AI` - AI-бот в экосистеме Sorrel Hub.
- `ExploitRPC` - open-source Windows tool для Discord Rich Presence.

## Почему история выглядит волнами

Sorrel Hub не появился сразу как готовый коммерческий продукт. Он рос через Discord-серверы, Roblox-скрипты, визуальные обновления, перезапуски и новые названия.

Основные эпохи:

1. Первая идея и старый Sorrel Hub.
2. Официальное удаление старого Sorrel Hub.
3. Невышедший Sorrel Hub v2.
4. Попытка revival под английскую аудиторию.
5. `NSW x SH`.
6. `Sorrel Hub: NextGen`.
7. Текущий переход к более понятной web/dev-экосистеме.

## Что значит NextGen

`NextGen` - это название текущей эпохи. Оно не обязано оставаться вечной частью бренда.

Правильнее читать так:

```txt
Sorrel Hub - основной бренд
NextGen - текущий chapter/reboot
```

В будущем публичное название может снова стать просто `Sorrel Hub`.
