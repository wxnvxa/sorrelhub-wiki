# Бренд

## Название

Основной бренд:

```txt
Sorrel Hub
```

Текущая эпоха:

```txt
Sorrel Hub: NextGen
```

`NextGen` не обязательно должен оставаться вечной частью названия. Это скорее marker текущей эпохи после перезапуска.

## Происхождение

Название родилось из двух частей:

- `sorrel` - щавель
- `hub` - слово из Roblox script hub-культуры

Рабочее объяснение:

```txt
Sorrel Hub started as a Roblox script hub idea and grew into a broader dev ecosystem.
```

## Логотипы

Известные этапы:

1. Самая первая версия логотипа Sorrel Hub, старше года.
2. Весна 2025 - Photoshop-версия логотипа.
3. Сентябрь-октябрь 2025~ - английская / early NextGen версия.
4. Текущий Sorrel Hub: NextGen logo.
5. Невышедшая v2-анимация.

Файлы лежат в:

```txt
assets/logo/
```

## Стиль

Текущий web/API стиль:

- черно-белая палитра;
- `JetBrains Mono Medium`;
- аккуратный минимализм;
- меньше лишнего декора;
- backend/API экран должен выглядеть как техническая точка, а не как landing.

## Позиционирование

